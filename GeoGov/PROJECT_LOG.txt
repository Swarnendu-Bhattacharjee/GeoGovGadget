  - Fix: Use approx.reshape(-1, 2).tolist() for flat coordinate list

  - Problem: Typo in convexHull call caused AttributeError
  - Fix: Correct import reference to cv2

MISTAKE 3: Over-segmentation with adaptive threshold (THRESH_BINARY_INV)
  - Problem: Filling entire image white; 1 massive contour at 91% image area
  - Fix: Added white_ratio check (>50% triggers fallback modes)
  - Added max_contour_area = img_area * 0.3 limit in find_building_contours

MISTAKE 4: fillPoly with 'alpha' kwarg
  - Problem: cv2.fillPoly() does NOT support 'alpha' parameter (OpenCV 5.0)
  - Fix: Use cv2.addWeighted() for semi-transparent overlay instead

MISTAKE 5: Color-based detection over-segmentation
  - Problem: Color mask (low_sat < 30) caught too many small noise pixels
  - Fix: Only use color as fallback when grayscale yields <3 valid contours
  - Filter color contours by area bounds and max_contour_ratio

MISTAKE 6: Not filtering giant background contours
  - Problem: Giant contour (91% of image) passed solidity check (0.99)
  - Fix: Added max_contour_area = img_area * 0.3 limit

MISTAKE 7: Per-pixel noise in synthetic test images
  - Problem: Per-pixel random noise made buildings indistinguishable from background
  - Fix: Use block-based noise (50x50 blocks) for cleaner test images

MISTAKE 8: Wrong threshold direction on adaptive
  - Problem: THRESH_BINARY_INV caught everything when buildings were darker
  - Fix: Check white_ratio and try both binary and inverted

MISTAKE 9: Using bitvise NOT on grayscale instead of proper contour extraction
  - Problem: Bitwise operations on grayscale created artifacts
  - Fix: Use proper HSV masking with per-channel operations

MISTAKE 10: Auto-detection misclassifying PLOTTED as RAW

REMINDER — Mistake Analysis & Future Prevention
================================================================================

MISTAKE 12: False positive vegetation pickups
  - Problem: The RAW detector picks up large vegetation patches (tree canopies,
    parks, grass buffers) as building footprints. Example: "law school.png"
    detects #0 as a large triangular park area instead of a building.
  - Root cause: CLAHE enhances contrast on vegetation edges too; Otsu/
    adaptive thresholds capture green vegetation as white blobs. The solidity
    filter (> 0.3) doesn't help because tree canopies can be solid shapes.
  - Fix approach (not yet implemented): Add HSV-based vegetation mask to
    preprocess — exclude pixels in green hue range (35-85) BEFORE thresholding.
    Formula: mask = non_green AND (otsu_result OR adaptive_result)
  - Current workaround: min_area=300 filters some small vegetation; but
    large tree canopies still pass through.

MISTAKE 13: Over-counting on high-density urban areas
  - Problem: Example images with 76 and 58 buildings likely have many false
    positives (shadows, small structures, parked cars detected as buildings).
  - Fix approach: Add minimum dimension check (min width AND height > 30px)
    in addition to area filtering. Shadows are often thin/long and would be filtered.

MISTAKE 14: No confidence scoring per detection
  - Problem: All detected buildings are treated equally — no quality metric.
  - Fix approach: Add per-contour confidence score based on:
    a) Area relative to median building size
    b) Solidity score (more rectangular = more likely building)
    c) Edge continuity (buildings have sharp, clean edges)

MISTAKE 15: Composite image loses positional accuracy
  - Problem: Composite places each image at top-left (0,0) — all 10 RAW images
    overlap in the same region. No spatial arrangement preserved.
  - Fix approach: Either (a) stack images with gaps/labels, or (b) use actual
    GPS coordinates if available. Currently composite is just for visual
    inspection of detection quality, not spatial accuracy.

LESSON LEARNED: Classical CV (CLAHE + Otsu + contours) works well for clear
satellite imagery but struggles with:
  1. Vegetation-rich areas (false positives)
  2. Low-contrast images (needs Canny/inversion fallback)
  3. High-density urban areas (over-segmentation)
  4. Annotated dataset images (pre-existing labels interfere)

For SIH submission: The current pipeline produces valid GeoJSON output with
building polygons — acceptable for the prototype. For production, integrate
TensorFlow U-Net/Mask R-CNN as described in the PPT for better accuracy.
