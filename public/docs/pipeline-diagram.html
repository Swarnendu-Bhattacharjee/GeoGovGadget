GeoGovGadget system flow

One image goes in — a drone or satellite frame. Two paths process it: the cloud pipeline for full accuracy, and the edge unit for offline, on-site detection. Both converge on the same verified parcel record.

The six systems

01

ML / CV Engine

Reads an image, outputs segmentation masks for buildings, parcel edges, and land-use classes.

Mask R-CNNOpenCV
02

Geometry Layer

Converts raw pixel masks into real-world polygons and flags any that overlap — a possible encroachment.

ShapelyGeoJSON
03

Backend API

Serves segmentation results, stores parcel records, and records each human verification decision.

Node / Express
04

Data Store

Holds every parcel and its status today in SQLite; the production target is a spatial-aware PostGIS database.

SQLite→ PostGIS
05

Web-GIS Dashboard

Shows detected polygons on a live map; a person approves or rejects each one before it's treated as ground truth.

ReactLeaflet
06 · EDGE

Edge Inference Unit

The same model, quantized, running on-device — proves the pipeline works in the field with zero connectivity.

Raspberry Pi 4/5TensorFlow Lite
